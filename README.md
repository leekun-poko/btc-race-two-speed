A two-speed cbBTC trading bot for the 24-hour live race: it buys dips inside an intact uptrend and rides confirmed breakouts, with take-profit, stop-loss, trailing and trend-break exits sized to stay above the round-trip cost. It starts flat and risks capital only when one of its two setups fires.

## Run it

```sh
node main.ts
```
